# 碎境 · 第二阶段素材交付候选

状态：已制作，等待用户逐项验收；未进入第三阶段应用开发。

打开 `index.html` 查看实际 GLB 三维预览、碎片分离展示、UI 导出和全部音效。需通过本地 HTTP 服务打开（例如 `python3 -m http.server 4175 --directory assets/phase-2`），避免浏览器对本地模型加载的跨域限制。

## 内容

- 15 件内置物品，各有完整模型、对应渲染碎片、封闭实体碎片和组合凸碰撞体，合计 **431 个实体碎片**。
- 43 个音效（其中12个为CC0实录剪辑，其余31个保留原创合成）：玻璃/陶瓷/电子塑料/自定义通用四组，每组投掷、碎裂、碎片落地各三个变体，共36个；另7个UI音效。全部为48kHz、单声道、PCM16 WAV。额外四段材质串联试听不计入43个独立样本。
- UI 素材：自定义面板、按钮状态、刷新/重置/Logo矢量，应用图标前景/背景/单色层与多尺寸PNG，中英文独立2倍分辨率参考图，分离的本地化文字目录。

## 三维模型使用约定

每个 `models/<稳定物品ID>/` 目录包含：

| 文件 | 用途 |
| --- | --- |
| `intact.glb` | 完整物品的PBR渲染模型 |
| `fragments.glb` | 分材质的碎片渲染层级；`fragment-000`等父节点下有表面子网格，可保留釉面与内部陶胎区别 |
| `fracture-solids.glb` | 每个碎片一个封闭实体网格，用于体积、质量与拓扑验证，不替代分材质渲染版 |
| `collision-hulls.glb` | 每个碎片的组合凸体候选；后缀`-hull-00`等属于同一个碎片 |
| `metadata.json` | 质量、米制尺寸、体积、质心、惯量、节点映射、碰撞近似误差 |

坐标为右手系、Y向上、米制。完整模型底部位于Y=0；碎片局部原点为各自质心，父节点平移恢复装配位置。运行时应把所有属于同一fragment的渲染子节点和凸体绑定到同一个刚体，禁止把每个材质子网格误当作独立碎片。

碎片质量按实体体积分配，合计保持原物品质量；玻璃和陶瓷先做实体并集再切分；电子塑料保留结构部件边界，逐部件扣除与先前部件的交叠后再切分，屏片、键帽、电路板及芯片可独立脱离。密闭空腔保留负边界，不将其当成实体碎片。切分后的总体积与完整实体并集在记录容差内守恒。片数预算因物体原有分离零件可能略增，实际数量见manifest。

碰撞候选为 **2,206 个组合凸体**，并非精确凹曲面。细薄曲面存在保守过覆盖，`convexHullVolumeRatio`逐片记录。GLB量化导致的凸性判断按相对体积误差小于1e-5验证；不以浮点严格相等冒充几何精度。第三阶段需在目标物理引擎检验间隙、反弹、堆积以及永久碎片的性能，必要时调整凸体分解。此阶段不声称设备性能或真实物理已验证。

玻璃导出使用glTF的透射/折射率材质扩展；目标PICO版本是否原样支持这些扩展尚未验证，需要第三阶段公开SDK能力核对与实际加载。网页查看器使用真实GLB，但不证明PICO材质一致。

## 制作方式与出处

官方 Spatial Editor 托管制作已实际尝试，发生执行令牌读取、遗留会话占用及恢复取消，未产生模型。原始记录见`review/editor-*.json`，制作决策见`review/production-ledger.md`。

本交付候选改用项目原创参数化网格、实体平面切分和PBR材质导出，不是官方托管Editor完成的bundle；不提供虚构的Editor门禁通过或provenance。

几何、微纹理与UI矢量均为本项目制作，没有下载第三方日用品模型。音频修订第2版将玻璃/陶瓷的碎裂与落地12个文件改为已核验CC0标注的第三方实物录音剪辑，作者为Joseph Sardin；来源、原始WAV和处理区间保存在audio/SOURCES.md与audio/sources/。其余31个文件保留原创程序化合成。最终听感仍需用户试听确认。

`vendor/three/`仅用于评审页WebGL展示，附MIT许可证；不是APK运行时依赖。制作源保留在项目`tools/assets/`，交付包内`production-sources/`也保留素材生成脚本；不包含Python虚拟环境或node_modules。

## UI使用约定

面板背景和功能图标为可复用矢量/PNG；`*-zh@2x.png`和`*-en@2x.png`是单语言排版参考，正式Compose界面应使用独立文字、动态计数和自定义绘制，不能把整张参考图当成交互控件。

应用图标无文字，中英文系统共享图形，名称仍分别显示“碎境”或“Shatter Realm”。分层SVG是制作源；第三阶段再转换为Android资源并配置manifest。当前未写APK，也不将1024px评审母图冒充PICO商店已验收图标。

## 验证范围

`review/asset-validation.json`：文件完整性、GLB嵌入资源、封闭网格、体积/质量守恒、组合凸体、WAV格式与无削波检查。

`review/browser-model-checks.json`：15件物品的完整/碎片/碰撞体均在WebGL中加载；渲染截图是素材预览，不是PICO运行截图。

`review/gallery-checks.json`：评审页资源、控件和音频链接检查。

**没有验证**：PICO手部追踪、真实平面、运行时碎裂、重力/反弹、APK构建、头显性能与舒适性。它们属于第三阶段，需要第二阶段素材确认后才实施。

请审阅模型轮廓、透明材质、碎片切面、UI和音色；全部素材确认后进入第三阶段。
